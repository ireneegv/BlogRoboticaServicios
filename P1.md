# PRÁCTICA 1

---

En esta práctica se nos pide programar una aspiradora robótica de gama alta para que limpie una casa de manera eficiente.
Para ello he registrado el mapa y he implementado el algoritmo BSA planificando una ruta, y mediante una máquina de estados y un controlador he corregido las desviaciones del robot debido al ruido de la imagen real y el camino planificado generado desde la imagen.

## FASE 1: REGISTRO DEL MAPA

---

Necesitamos coger unos píxeles de referencia para obtener la relación entre la posición real del robot y la del mapa.

* Primero he aplicado una erosión a la imagen del mapa proporcionada y he creado una matriz de transformación para obtener la posición 2D del robot.

## FASE 2: PLANIFICACIÓN DE CAMINOS

---

Divides el mapa en píxeles prioritarios y el robot debe ir moviéndose hacia esas prioridades mientras marca los puntos de retorno. La rejilla tiene el tamaño del robot; si la ponemos más grande, habrá zonas que no se limpien.

## FASE 3: NAVEGACIÓN LOCAL

---

En la fase 3 he implementado un controlador para que el robot siga la ruta planificada en la fase 2, corrigiendo las desviaciones durante el movimiento. Para ello, obtengo la posición y orientación reales del robot mediante 
HAL.getPose3d() y las comparo con las del siguiente objetivo. Calculo la distancia y el error angular para decidir si el robot debe girar o avanzar. He usado un controlador proporcional (P)
```
w = KP_W * error_angular
```
 para corregir la orientación y ajusta la velocidad lineal según la distancia al objetivo. Cuando alcanza una celda dentro de la tolerancia establecida, pasa al siguiente objetivo de la ruta. 
Además, debido a el error acumulado entre el mapa y las medidas reales de la casa el robot a veces no conseguia llegar a la habitacion debido a que se chocaba con la puerta como se puede ver en esta imagen.

Para resolver el problema he implementado una maquina de estados. Cuando detecta una colisión mediante el bumper, el robot se detiene, retrocede y gira para esquivar el obstáculo. Si choca tres veces en el mismo objetivo, realiza una evasión más larga y lo abandona para evitar quedarse atascado. Finalmente, cuando termina de recorrer la ruta, el robot detiene su movimiento.
